# MicroPAD--6

<img width="642" height="632" alt="Screenshot 2026-09-19 042501" src="https://github.com/user-attachments/assets/d5c03c97-3d04-4168-a0bb-ef24c3a3cff3" />

So I made a 6 Switch MacroPad ,which has a rotor encoder at the top for brightness controlee as well . It is based on Xiao Rp2040 and has per switch LED as well and the display shows how much time are you working for . Also we used diodes to prevent ghosting .The PCB was designed on kicad and CAD was done on Fusion . firmware was written in VS-Code. It has a very compact design.

## Features
 - Based on Xiao Rp2040 
 - had compact layout
 - Per Switch LED and diode for ghosting prevention
 - USB-C Type for Connection
 - Uplifted CAD Design for comfortable typing
